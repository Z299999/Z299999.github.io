# Where the Research figures come from

The five banners in `assets/img/research/` are renewable: each is cut from a
master that lives elsewhere, and this file is the rebuild method. All are
2400 px wide, WebP quality 90, never upscaled (the rule is in the HTML comment
above the Research entries in `index.html`).

Each was re-cut on 2026-10-02 by finding the published 1600 px image inside
its master by normalised cross-correlation (score in brackets), so the 2400
version is the same crop, not a re-composition.

`render_still.py`, `pose_multi.py` and the correlation matcher `match_crop.py` are
scratch tools, not in this repo; the commands above are complete enough to
rewrite them. `pose_multi.py` must wait for the screenshot file to appear and
then kill Chrome's process group — on this machine headless Chrome writes the
file and does not exit.

The Open Graph preview for `/research/` is `hexapod-terrain-og.jpg`, a JPEG
copy of the hexapod banner: link-preview bots are not all WebP-aware.
